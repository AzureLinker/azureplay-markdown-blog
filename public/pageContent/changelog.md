## 0.2.0-beta (2026-03-29)
- Теперь `.json` файл с постами не содержит всё содержимое `.md` файлов, что значительно снижает вес базы данных.
- Сайт теперь берёт название `.md` из `.json`, и загружает его в сыром виде, так что загружать исправления статей гораздо проще.
- Теперь также создаётся отдельный `.json` файл, где хранятся теги. Они отображаются рядом с постами. Это подготовка базы для поиска статей по тегам.
- Добавлена пагинация для всех статей, так что на одной странице показывается не более 10 постов.
- Добавлена кнопка скачивания поста.
- Теперь страница 404 отображается при любых неправильных адресах.
- Теперь в подвале сайта указывается версия самого сайта.
